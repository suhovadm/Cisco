# Cisco
Примеры различных конфигов и настроек.
________________________________________________________________________________________________________________________________________________
| Обозначение | Расшифровка               | Скорость                |
| :---------- | :------------------------ | :---------------------- |
| **fa 0/1**  | FastEthernet              | **100 Мбит/с** (100 Mbps) |
| **gi 0/1**  | GigabitEthernet           | **1 Гбит/с** (1000 Mbps) |
| **te 0/1**  | TenGigabitEthernet        | **10 Гбит/с** (10 Gbps) |
| **fo 0/1**  | FortyGigabitEthernet      | **40 Гбит/с**           |
| **hu 0/1**  | HundredGigabitEthernet    | **100 Гбит/с**          |

Обозначение ga встречается крайне редко (в старых Catalyst 4000, но стандарт де-факто - это gi).  
Если увидим где-то вот такую запись: gi 0/1.10 - это гигабитный порт с 10-м VLAN-ом.
