Базовая конфигурация Cisco SW (БЕЗ IP-ТЕЛЕФОНОВ)

СХЕМА:
Gi0/1 ---> Router (Trunk)
Gi0/2-48 ---> ПК (access VLAN 10)
VLAN 10 ---> DATA
VLAN 999 ---> Native / BLACKHOLE

1. Вход в режим конфига
enable
conf t

2. Включаем RSTP
spanning-tree mode rapid-pvst

3. (Опционально) LLDP
Можно оставить - полезно для диагностики, но телефонов нет, поэтому не критично:

lldp run

4. Создаём VLAN-ы

vlan 10
 name DATA
exit

vlan 999
 name UNUSED_NATIVE
exit

5. Trunk к маршрутизатору (Gi0/1)

interface GigabitEthernet0/1
 description LINK_TO_ROUTER

 switchport mode trunk
 switchport nonegotiate

 switchport trunk native vlan 999
 switchport trunk allowed vlan 10,999

 spanning-tree portfast trunk

 no shutdown
exit

6. Порты для ПК (Gi0/2-48)

interface range GigabitEthernet0/2-48

 switchport mode access
 switchport access vlan 10

 switchport nonegotiate

 spanning-tree portfast
 spanning-tree bpduguard enable

 no shutdown
exit

7. Дополнительная стабильность (опционально)

errdisable recovery cause bpduguard
errdisable recovery interval 300

8. Сохраняемся

end
write memory

# ИТОГОВАЯ ЛОГИКА:
Один VLAN (10) = весь пользовательский трафик
Trunk = только маршрутизатор + VLAN 10 и native 999
Access порты = строго ПК
RSTP + BPDU Guard = защита от петель
