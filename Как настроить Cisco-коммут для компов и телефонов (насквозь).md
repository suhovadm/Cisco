Как настроить Cisco-коммут для компов и телефонов (насквозь)?  

Как это работает?  
IP-телефон подключается к патч-розетке, а компьютер подключается к телефону.  
Розетка --> Телефон --> ПК.  

Разделение трафика происходит следующим образом:  
ПК --> untagged --> VLAN 10 (DATA),  
Телефон --> tagged --> VLAN 20 (VOICE).  

ПОГНАЛЕ!  

enable # Переходим в режим Рута  
configure terminal # переходим в режим настроек  
 
spanning-tree mode rapid-pvst # включаем RSTP  

mls qos # включаем QoS  

lldp run # включаем LLDP (позволяет устройствам видеть друг друга)  

vlan 10 # создаём 10-й VLAN для компов  
 name DATA  
exit  

vlan 20 # создаём 20-й VLAN для телефонов  
 name VOICE  
exit  

interface range gi0/2-48 # выбираем диапазон портов с 2 по 48.  

 switchport mode access # переводим порты в режим ACCESS  
 switchport access vlan 10 # все access порты на 10-й VLAN  
 switchport voice vlan 20 # весь телефонный трафик - в 20-й  

 spanning-tree portfast # ускоряем поднятие порта (убирает задержку в 30-50 секунд ожидания STP-протокола)  
 spanning-tree bpduguard enable # включает защиту от петель (если подключить другой свитч - порт отключится)  

 mls qos trust cos # доверять приоритетам телефона (короче, эта команда говорит чтобы коммут доверял телефону)  

 lldp transmit # с помощью этой команды, коммут отправляет информацию о себе соседним устройствам  
 lldp receive # с помощью этой команды, коммут слушает, что говорят устройства подключенные к порту  
 (важно для автоопределения voice VLAN)  

exit  

end  

copy running-config startup-config # сохраняемся! Также можно командой write memory
