Что делает эта схема?  

Это конфига двух маршрутизаторов Cisco (R1 и R2).  
Главная задача этой конфиги - соединить две локалки (LAN) через  
два роутера и настроить динамическую маршрутизацию с помощью EIGRP.  

R1 обслуживает сеть 10.1.1.0  
R2 обслуживает сеть 10.2.2.0  
Между R1 и R2 есть соединение 10.0.12.0  
EIGRP соединяет две сети, но только Cisco-only.  
Если у нас что-то другое, тогда нужно поднимать OSPF.  
____________________________________________________________________________________________  

* Разберём команды на R1.  

// Переходим в режим настройки.  
en  
conf t  

// Настройка первого интерфейса.  

// Выбираем интерфейс GigabitEthernet 0/0.  
// Это физический порт маршрутизатора, к которому, например, подключается локальная сеть.  
interface gigabitEthernet 0/0  

// Назначаем интерфейсу IP-адрес и маску подсети. Маска /24.  
ip address 10.1.1.1 255.255.255.0  

// Активируем порт, выходим.  
no sh  
ex  

// Теперь второй интерфейс.  
// Выбираем второй физический порт маршрутизатора.  
interface gigabitEthernet 0/1  

// Назначаем ему IP-шник и маску подсети. Маска 30, она вмещает всего 4 адреса.  
ip address 10.0.12.1 255.255.255.252  

// Поднимаем порт, выходим.  
no sh  
ex  

// Настройка EIGRP.  

// Запускаем настройку протокола динамической маршрутизации EIGRP.  
// EIGRP (Enhanced Iterior Gateway Routing Protocol) - протокол, который позволяет  
// маршрутизаторам автоматически обмениваться информацией о доступных сетях.  
// 100 - номер автономной системы (AS-ки).  
// На обоих маршрутизаторах номер AS-ки должен совпадать, иначе чуда не случится.  
router eigrp 100  

// Указываем EIGRP, что нужно работать с сетью 10.1.1.0/24  
// 10.1.1.0 - адрес сети  
// 0.0.0.255 - обратная маска подсети.  
// Обратная маска используется для определения IP-адресов, к которым применяется команда network.  
network 10.1.1.0 0.0.0.255  

// Указываем ещё одну сеть, которую нужно включить в EIGRP.  
// Это сеть, соединяющая R1 и R2.  
// В данном случае это сеть 10.0.12.0/30, по wildcard маска будет 0.0.0.3  
network 10.0.12.0 0.0.0.3  

// Запрещает отправку служебных пакетов EIGRP (Hello) через указанный интерфейс,  
// предотвращая формирование соседства с другими маршрутизаторами в локальной сети.  
// При этом сеть продолжает работать через EIGRP как и раньше.  
// Команда абсолютно опциональная, её можно не добавлять.  
passive-interface gigabitEthernet 0/0  

// Отключаем автоматическое суммирование маршрутов.  
// Это позволяет EIGRP передавать информацию о сетях без автоматического объединения их  
// в более крупные классовые сети.  
no auto-summary  

// Выходим.  
ex  

* DHCP  

// Исключаем диапазон IP-адресов от 10.1.1.1 до 10.1.1.10 из автоматической выдачи DHCP.  
// Зачем? Чтобы эти адреса можно было использовать для роутера, серверов и других  
// устройств со статическим IP.  
ip dhcp excluded-address 10.1.1.1 10.1.1.10  

// Создаём пул с названием LAN1.  
ip dhcp pool LAN1.  

// Указываем сеть, из которой DHCP будет выдавать адреса.  
network 10.1.1.0 255.255.255.0  

// Указываем шлюз по умолчанию для компьютеров.  
// Т.е. компьютер будет отправлять пакеты в другие сети через R1 с адресом 10.1.1.1.  
default-router 10.1.1.1  

// DNS-ом ставим Google.  
dns-server 8.8.8.8  

// Поднимаемся до корня, сохраняем конфигу.  
end  
wr

* Теперь разберём команды на R2.  

// Заходим в режим конфига.  
en  
conf t  

// Настройка первого интерфейса.  

// Выбираем первый интерфейс на R2.  
interface gigabitEthernet 0/0  

// Назначаем IP-шник и маску. Маска /24.  
ip address 10.2.2.1 255.255.255.0  

// Поднимаем интерфейс, выходим.  
no sh  
ex  

// Настройка второго интерфейса.  
interface gigabitEthernet 0/1  

// Назначаем IP-шник и маску. Маска /30 означает, что в подсети всего 4 адреса.  
// IP-шник 10.0.12.2 находится в одной подсети с R1, поэтому маршрутизаторы могут общаться друг с другом.  
ip address 10.0.12.2 255.255.255.252  

// Поднимаем, выходим.  
no sh  
ex  

// Настройка EIGRP.  

// Включаем EIGRP с номером AS 100.  
router eigrp 100  

// Добавляем локальную сеть R2 в EIGRP.  
network 10.2.2.0 0.0.0.255  

// Добавляем сеть соединения R1 и R2 (маска по wildcard также /30).  
network 10.0.12.0 0.0.0.3  

// Запрещает отправку служебных пакетов EIGRP (Hello) через указанный интерфейс,  
// предотвращая формирование соседства с другими маршрутизаторами в локальной сети.  
// При этом сеть продолжает работать через EIGRP как и раньше.  
// Команда абсолютно опциональная, её можно не добавлять.  
passive-interface gigabitEthernet 0/0  

// Отключаем автоматическое суммирование маршрутов.  
no auto-summary  

// Выходим.  
ex  

* DHCP  

// Исключаем адреса от 10.2.2.1 до 10.2.2.10 из выдачи DHCP.  
ip dhcp excluded-address 10.2.2.1 10.2.2.10  

// Создаём DHCP-пул с названием LAN2.  
ip dhcp pool LAN2  

// Указываем сеть, из которой будут выдаваться IP-адреса.  
network 10.2.2.0 255.255.255.0  

// Указываем шлюз по умолчанию - интерфейс R2.  
default-router 10.2.2.1  

// Указываем DNS-ом Google.  
dns-server 8.8.8.8  

// Поднимаемся до корня, сохраняем конфигу.  
end  
wr
